# Lookout 使用教程

[English](TUTORIAL.md) · **简体中文**

原生 Swift / AppKit / SwiftUI 菜单栏软件。通过摄像头检测人脸朝向，转头或离座后模糊所有屏幕；回正后恢复。适合摄像头位于屏幕侧边的布局。

## 使用

1. 将 Lookout.app 放进“应用程序”，打开并允许摄像头权限。
2. 选择摄像头，必要时调整画面旋转。
3. 自然坐好、看着屏幕，点击“使用当前坐姿”，保持约 1 秒。
4. 水平与垂直各有独立转轮，可拖动或输入各自的基准角度；可分别校准一个方向，也可点击“同时校准”。蓝色指针为基准，绿色为实时角度，浅蓝弧为允许范围。它们均相对摄像头坐标；是否偏离以校准后的差值判断。
5. 分别调整左侧、右侧、抬头、低头的允许角度；需要时开启“启用垂直保护”，然后点击“应用并开始保护”。设置窗口关闭后生效。
6. 随时从菜单栏眼睛图标选择“立即解除遮挡并暂停”。打开设置也会暂时解除遮挡。

设置窗口支持 Cmd+W。关闭后隐藏 Dock 图标，继续在菜单栏运行。暂停且未打开设置时释放摄像头。锁屏与睡眠期间停止摄像头，恢复后重新获取稳定人脸。每次启动需要手动开始保护，不自动启用。

关闭设置而未应用会丢弃本次调整，继续使用上次应用的配置。

## 默认行为

- 正常方向需要校准或手动设置；摄像头和画面旋转改变后需重新校准。
- 左右允许角度默认各 30°；持续偏离 0.6 秒后遮挡。
- 连续 1.2 秒没有检测到人脸 / 无法估计朝向后遮挡。
- 回到更小的恢复范围并稳定 0.35 秒后解除，避免边界闪烁。
- 摄像头帧超过 1.5 秒不更新，或分析出错时保持遮挡。
- 垂直角度检测默认关闭，可独立开启，使用专属转轮设置基准和上下独立阈值。垂直转轮为侧视图：零度朝右，抬头向上转、低头向下转。
- 0.1.0 的已保存设置会自动沿用，原垂直容忍角度同时用于抬头和低头。
- 约每秒分析最多 8 帧，优先使用 640×480 采集，不录音。

## 原型限制

遮挡面部可能在仍能检测到人脸时干扰角度估计。0.1.1 没有修改朝向估计或增加平滑滤波；绿色指针仍显示实时估计。

**当前版本检测人脸存在及头部朝向，不验证身份。别人坐到摄像头前也可能解除遮挡。** 多人场景优先跟踪上一帧附近的人脸，否则选择较大人脸。这只是位置连续性，不是身份识别。

头部朝向不等于眼球视线。低光、遮挡、大侧脸、反光眼镜可能导致检测丢失。侧放摄像头也存在可见角度的物理限制，校准不能恢复不可见的人脸。建议先在日常坐姿下调试。

模糊跟随 HeadOrbit 的思路，使用动态加载的私有 WindowServer 接口 `CGSSetWindowBackgroundBlurRadius`。它可能随 macOS 版本改变，不适合 App Store。接口缺失或返回失败时使用不透明黑色遮挡。接口返回成功并不能证明所有系统版本的视觉效果正确，需要实机验证。

它是视觉遮挡工具，不是系统锁屏、认证机制或防截图工具。不要依赖它保护敏感资料。菜单栏有意保持可操作。摄像头故障不会使你失去菜单栏暂停入口。

## 隐私与权限

只请求摄像头权限，不请求麦克风、辅助功能或屏幕录制权限。分析在本机 Vision 完成，画面只用于内存中的预览与检测，不保存、不上传；程序无网络功能。启用摄像头时系统指示灯会亮起。配置以 UserDefaults 保存在本机。

## 构建与验证

需要 macOS 14+、Apple Silicon 和可用的 Xcode Command Line Tools。

```sh
bash build.sh
bash test.sh
open build/Lookout.app
```

应用使用临时本机签名，未公证。首次启动请按 macOS 的提示通过“隐私与安全性”允许打开。

自动测试覆盖基准偏移、左右独立阈值、持续时间、回正迟滞、离座、摄像头故障和垂直角度。真实摄像头识别准确率、资源占用、多显示器和全屏应用覆盖仍需实机测试。
